   - Ollama (`qwen2.5:7b`, already on the server): wizard step 3 "describe the project" with two
     descriptions (structured list, free prose; 10–15 tasks each) → review table → save; a status
     message with two facts ("Ania jest chora do piątku, a logowanie zajmie jeszcze 3 dni dłużej")
     → items to confirm → saved; an AI explanation on a recommendation with its faithfulness badge.
   - OpenRouter (`openai/gpt-oss-120b`, pinned to Groq, key in `.env`): the same three flows once.
     Budget: under 0.20 USD in total; record tokens.
   - Check: the absence reason ("chora") never appears in stored data, logs, caches or pages
     (grep the data dir and the cache files), with `store_prompts = false` for these runs; errors
     from the model (invalid JSON, timeout, provider down) show a friendly message and the form
     still works; the app settings page tests each provider.
   Fix what breaks (separate `WP11 fix:` commits with tests) and document the results, including
   the model's quality on these flows, in the report.

   (`docs/reports/WP11.md`).
</task>
