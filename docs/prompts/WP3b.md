RQ3: *Does the Monte Carlo forecaster give calibrated and sharp early warnings of a deadline
miss, and how much better is it than the deterministic plan-based estimate that classical PM
tools show?* WP3b runs the true world under NoReaction, stops at checkpoints, asks several
forecasters for `P(C ≤ D)` and a makespan distribution using only the `Observation`, and scores
them against the realised makespan. A second, smaller study tests robustness when the
forecaster's priors are wrong (the agent never knows the true disruption rates).

Architect's answers to the WP3a spec questions (binding):
1. §5 urgency: **all** running activities use `τ_j = LF_j − t − E[remaining_j]`, with or without
   absent members. Keep the v1.4 text and add the words "regardless of absences".
2. Empty absence support: accepted as implemented (smallest admissible `L`, counted as a
   fallback). Add one sentence to §5.1.
3. "Size-biased" was the architect's wording error; the §5.1 formula and the test are correct.
   No change.

1. **Checkpoint observations.** Add a way to obtain `Observation`s from a true-world run on
   given days without changing its results (e.g. `simulate(..., observe_days=...)` returning
   them in the result, or a callback). Checkpoint days: `t_f = floor(f · C_plan)` for
   `f ∈ {0, 0.2, 0.4, 0.6, 0.8}`, `C_plan` = baseline makespan. If the project has already
   finished at `t_f`, record the checkpoint as skipped. Test: results with and without
   observation recording are identical.
2. **Forecasters** (all receive only the `Observation` and the plan):
   - `mc_full`: WP3a `forecast`, `n_rollouts = 200`, future disruptions on;
   - `mc_no_future`: the same, future disruptions off (beliefs about the current hidden state
     only);
   - `deterministic`: what a classical PM tool shows. One run from the observed state with
     remaining work of unstarted activities = `p_j`, of started activities =
     `max(p_j − e_j, one crew-member day)` (shocks observed so far applied by their factors),
     absent workers returning after their announced bound `L_low`, no future disruptions,
     NoReaction. Point forecast `Ĉ`; `P(C ≤ D) = 1[Ĉ ≤ D]`.
   All forecasters at the same checkpoint use the same forecast seed (CRN).
3. **Study runner** `src/sentinel/experiments/forecast_study.py`, config
   `configs/wp3_calibration.toml` (`experiment-run` skill):
   - sets `j30`, `j60`, all 480 instances, baseline `cpsat_det`, `C*` as in WP2b;
   - scenarios: the primary grid of `plan.md` (`δ_D = 0.2`, `λ_A ∈ {0, 0.005, 0.01, 0.02}`,
     `E[L] = 3`, `λ_S = 0.01`, `λ_N = 0.02`); `δ_D = 0.3` evaluated post hoc from the same
     samples (store what is needed);
   - replications `R = 4`; **world seeds exactly as in WP2b** for replications 0–3, so the
     realised makespans must equal the WP2b `results.csv` rows for the same (set, instance,
     scenario, replication). Add this as a check in the runner's summary (count of mismatches,
     expected 0);

     forecasters;
   - output `forecasts.csv.gz`, one row per (set, instance, scenario, replication, checkpoint,
     forecaster): checkpoint day, `f`, true makespan, `D` for both `δ_D`, `p_on_time` for both
     `δ_D`, mean, quantiles 5/10/25/50/75/90/95 %, the PIT pair `(F(C−1), F(C))` of the
     forecast CDF at the true makespan, CRPS (computed from the samples), fallbacks, wall time.
     Do not store samples.
4. **Metrics and summaries** (generated by code from `forecasts.csv.gz`; a separate
   `sentinel summarise-forecasts <run_dir>` command so they can be regenerated):
   - Brier score with the Murphy decomposition (reliability, resolution, uncertainty), 10
     equal-width bins; ECE; sharpness (variance of `p`); log score with `p` clipped to
     `[0.005, 0.995]`;
   - CRPS and MAE of the median, normalised by `C*`; coverage of the 80 % interval (10–90 %);
     randomised PIT histogram (10 bins) for the makespan;
   - early warning, threshold `θ ∈ {0.5, 0.8}`: among late runs, share warned (some checkpoint

     false-alarm share;
   - all broken down by set × checkpoint `f` × `λ_A` (and pooled), for `δ_D = 0.2` in the main

   - 95 % confidence intervals by **cluster bootstrap over instances** (1 000 resamples, fixed
     seed), including paired differences `mc_full − deterministic` and `mc_full − mc_no_future`

   - outputs `summary.md`, `table_wp3_calibration.tex` (pooled per set × `f` × forecaster:

     0.8}`, one line per forecaster, bin counts shown), `fig_wp3_brier.pdf/.png` (Brier vs `f`,
