The supervisor's own example: a person writes a 10-page report and AI edits it, removes
repetitions, marks the changes and adapts it for each department. Raporty builds exactly that,
with the change marking done by code and a fact guard; Finanse shows "AI summarises, never
approves"; RQ6 measures how safe the editing is; the survey (closing 22 November) gets an import
so Mapa granic can compare Sentinel's map with what people answered.
</context>
